# Canonical Telemetry Contract

The canonical telemetry schema is the main boundary between ECU-specific
implementation and the analyzer/application layer.

Source of truth: `app.domain.telemetry`.

## Schema Version

```text
canonical-telemetry-v1
```

`CanonicalTelemetrySession` rejects any other `telemetry_schema_version`.

## Signal Definitions

Current core signal columns:

```text
rpm
tps_voltage
tps_raw_candidate
battery_voltage
iat_c
ect_c_candidate
map_raw
```

Candidate signal columns:

```text
tps_raw_candidate
ect_c_candidate
map_raw
```

Default signal definitions:

| Signal | Status | Unit |
| --- | --- | --- |
| `rpm` | `high_confidence_candidate` | `rpm` |
| `tps_voltage` | `high_confidence_candidate` | `V` |
| `tps_raw_candidate` | `candidate` | `raw` |
| `battery_voltage` | `high_confidence_candidate` | `V` |
| `iat_c` | `high_confidence_candidate` | `degC` |
| `ect_c_candidate` | `candidate` | `degC` |
| `map_raw` | `candidate` | `raw` |

These statuses are part of the current schema but are not equivalent to the
decoder confidence labels in `HONDA_KEIHIN_DECODER.md`.

## `SamplingMetadata`

| Field | Type | Required | Validation |
| --- | --- | --- | --- |
| `sample_interval_ms` | float or null | no | Must be `> 0` if present. |
| `sampling_rate_hz` | float or null | no | Must be `> 0` if present. |

Derived property `time_basis`:

| Condition | `time_basis` |
| --- | --- |
| `sample_interval_ms` present | `relative_time_ms` |
| else `sampling_rate_hz` present | `sampling_rate_hz` |
| neither present | `sample_index` |

| Field | Type | Required | Semantics |
| --- | --- | --- | --- |
| `sequence` | int | yes | Zero-or-positive sample sequence. ML requires unique monotonic increasing sequence. |
| `timestamp_ms` | float or null | no | Non-negative. Session-local/source-relative milliseconds, not proven wall-clock time. |
| `rpm` | float or null | no | Required complete for ML-eligible samples. |
| `tps_voltage` | float or null | no | Required complete for ML-eligible samples. |
| `tps_raw_candidate` | float or null | no | Required complete for ML-eligible samples. |
| `battery_voltage` | float or null | no | Required complete for ML-eligible samples. |
| `iat_c` | float or null | no | Required complete for ML-eligible samples. |
| `ect_c_candidate` | float or null | no | Required complete for ML-eligible samples. |
| `map_raw` | float or null | no | Required complete for ML-eligible samples. |
| `frame_valid` | bool | no | Defaults true. Used for ML eligibility. |
| `checksum_valid` | bool | no | Defaults true. Used for ML eligibility. |
| `quality_flags` | object | no | Parser/decoder provenance and validation details. |
| `candidate_signals` | object | no | Extra decoder fields not part of core ML schema. |

ML-eligible sample:

```text
frame_valid == true and checksum_valid == true
```

## `CanonicalTelemetrySession`

| Field | Type | Required | Semantics |
| --- | --- | --- | --- |
| `session_id` | string or null | no | Generated by `AnalysisService` when missing. |
| `vehicle_id` | string or null | no | Metadata only. |
| `device_id` | string or null | no | Metadata only. |
| `firmware_version` | string or null | no | Metadata only. |
| `session_note` | string or null | no | Metadata only. |
| `ecu_profile_id` | string or null | no | Decoder/ECU profile provenance. |
| `decoder_id` | string | yes | Decoder provenance. |
| `decoder_version` | string | yes | Decoder provenance. |
| `telemetry_schema_version` | string | no | Defaults to `canonical-telemetry-v1`; only this value is accepted. |
| `sampling` | `SamplingMetadata` | no | Defaults to empty sampling metadata. |
| `samples` | list of `TelemetrySample` | yes | ML validation requires non-empty and at least one full window. |
| `signal_definitions` | object | no | Defaults to current signal definitions. |
| `source_type` | string | no | Defaults `canonical`; raw adapter uses `raw_compatibility_adapter`. |

Derived property:

```text
decoder_version_key = "{decoder_id}:{decoder_version}"
```

## Timestamp Semantics

`timestamp_ms` is a sample time on a session-local time axis.

For RAW compatibility imports it is:

1. JSONL `elapsed_ms`, `timestamp_ms`, or `device_time_ms` if present, else
2. computed from `sample_interval_ms` or `sampling_rate_hz`, else
3. `None`.

The repository does not prove absolute wall-clock capture timestamps for samples.

## RAW Adapter Provenance

The current RAW compatibility adapter creates canonical sessions with:

```text
ecu_profile_id = honda_keihin_legacy_29
decoder_id = honda_keihin_legacy_29
decoder_version = 0.1.0
source_type = raw_compatibility_adapter
```

Each sample includes quality flags:

- `parse_ok`
- `parse_error`
- `decoded_signals_valid`
- `validation_errors`
- `line_number`
- `source_format`
- `timestamp_source`

Extra candidate signals preserved under `candidate_signals`:

- `signal_b19`
- `signal_word_20_21`
- `signal_b22`
- `signal_b23`
- `signal_b24`

## Boundary Audit

Verified boundary:

- `app.services.analysis_service.AnalysisService.analyze` accepts
  `CanonicalTelemetrySession`.
- ML validation/windowing/features/inference operate on canonical samples or
  dataframes derived from canonical samples.
- Generic analysis does not import the runtime RAW decoder.

Known exceptions:

- `train_from_raw_files` converts raw files to canonical sessions before
  training.
- `profile_v02_training` is a profile-specific training/audit module and imports
  the Honda/Keihin profile directly.

## Compatibility Caveat

The canonical V1 core includes `ect_c_candidate` and `map_raw`, while profile
v0.2 evidence promotes `ect_c` from normalized byte 13 and rejects the old MAP
hypothesis. Current canonical runtime has not been redesigned to replace those
V1 fields. Consumers should treat the canonical schema as the runtime contract,
not as a final ECU science truth.
